Samples for Esmuflily
=====================

See also similar examples at Wiki.

*   "pivot-chord-symbols":

    Two samples with pivot chord symbols spanned over 2 or more notes.

    [See Wiki](https://github.com/tr-igem/esmuflily/wiki/Function-Theory-Symbols#example-2)

*   "sample":

    Short sample for [Esmuflily](https://github.com/tr-igem/esmuflily) +
    [Ekmelily](https://github.com/tr-igem/ekmelily) using `cosmufl.ily`.
    Adaption of a sample from [LilySMuFL](https://github.com/backseatviolist/lilysmufl).
    by Nathan Ho, Joram Berger.

    [See Wiki](https://github.com/tr-igem/esmuflily/wiki/Cosmuflily#example)

*   "system-start":

    System start delimiters `brace` and `bracket`.

    [See Wiki](https://github.com/tr-igem/esmuflily/wiki/System-Start-Delimiters#example)
